# Profile Card

HTML & CSS ile geliştirdiğim profil kartı mini projesi.

## Kullanılan Teknolojiler

- HTML5
- CSS3
- Google Fonts
- Boxicons

## Özellikler

- Profil kartı tasarımı
- Sosyal medya bağlantıları
- Hover animasyonu
- Responsive temel yapı
- Portföy sitesine yönlendirme
